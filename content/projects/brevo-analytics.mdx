## What it does

Shows workflow email performance inside an existing dashboard integration.

## Built with

Brevo API (transactional events endpoint).

## How I built it

- Pulled workflow email events from Brevo's transactional events endpoint.
- Split long date ranges into windows to work around the API's 90-day limit.
- Fed the results into the existing dashboard integration.
