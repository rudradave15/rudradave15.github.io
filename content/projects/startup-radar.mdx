## What it does

Finds startup ideas proven abroad that nobody has built in India yet.

## Built with

React, Anthropic API.

## How I built it

- Surfaces foreign startups and scores each one's fit for the Indian market.
- Finds existing Indian clones of each startup.
- Flags the ones with no Indian clone as open opportunities.
